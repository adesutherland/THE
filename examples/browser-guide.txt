Browser examples (0.10.dev review candidate)
========================================

Open these files from Files > Open. Missing bundled examples are copied into
the browser workspace when their runtime is present. Save your edits to keep
them; the site does not replace an existing workspace file.

Classic Rexx (.rexx)
--------------------
RexxRunner.rexx asks for a name in the Program console. RexxWords.rexx lists
the words in a sentence. RexxLedger.rexx shows a running balance; optionally
enter an opening balance as the first Program argument. Select a source file
and choose Run Classic Rexx beside its filename. ClassicDemo.rexx is a parser
and highlighting example; it is not intended as a runnable program.

Level B (.crexx)
----------------
LevelBSquares.crexx uses cREXX Level B arithmetic and a loop. Select the source
and choose Build source, then Run with cREXX beside its filename. The Program
console prints "Level B sum of squares: 55". This uses the browser compiler
and the isolated program VM; it requires the combined compiler/runtime bundle.

Level G (.crexx and .rxbin)
--------------------------
LevelGAccumulator.crexx uses a typed class and prints the sum of five squares
(55). LevelGFibonacci.crexx uses a typed routine and prints terms 0 through 10
(ending at 55). In a bundle with the cREXX compiler, select a .crexx source,
choose Build source, then Run with cREXX beside its filename. Build includes
unsaved edits. After editing, build again before Run; each build keeps its own
RXBIN image. This route supports self-contained source and imports from the
bundled standard library. Other workspace modules, native plugins and host
commands are not available to the browser compiler/runtime.

Matching PRECOMPILED images are also included. In Tools & Profiles select
RXBIN program, enter the image's workspace path, then choose Run with tool.
Alternatively, run the explicit path from the THE command field:

  RX RUN "/workspace/LevelGAccumulator.rxbin"
  RX RUN "/workspace/LevelGFibonacci.rxbin"

Each image was built with the native compiler matching this bundle's cREXX
runtime. A different bundle or runtime may require rebuilt images.

MiniBASIC (.bas)
----------------
MiniBASIC.bas adds 1 to 10, then asks for one number in the Program console.
MiniBASICPrimes.bas prints primes through 30. MiniBASICStrings.bas demonstrates
assigned, copied and quoted strings. The MiniBASIC files appear only in a
candidate with the MiniBASIC runner and highlighter. To enable Run for .bas:

1. The two RXBIN images are copied into the workspace if absent.
   If you removed them, use Tools & Profiles to import matching images.
2. In Files > Profile sources, open MiniBASIC-profile.the. Build profile, then
   Apply profile. This registers the imported runner and language service.
3. Open a .bas file and choose Run MiniBASIC beside its filename. For
   MiniBASIC.bas, enter a number when the Program console asks for input.

No example needs a host shell or access to your computer's files. Browser
workspace files persist for this origin and browser profile, subject to site
data retention. Program output is in the Program console.
