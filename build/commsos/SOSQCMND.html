SOS QCMND - move cursor to command line and clear

Syntax:
SOS QCmnd

Description:
The SOS QCMND command moves the cursor to the first column of the command line and clears it.

Compatibility:
XEDIT: N/A
KEDIT: Compatible

See Also:
SOS EXECUTE

Status:
Complete.
