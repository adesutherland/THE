SET TRUNC - specify the truncation column

Syntax:
[SET] TRunc n|*

Description:
The SET TRUNC set command determines the truncation column. This is the rightmost column of text upon which THE commands are effective.

Compatibility:
XEDIT: Compatible.
KEDIT: Compatible.

Default:
*

Status:
Incomplete.
