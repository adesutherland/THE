SET IDLINE - specify if IDLINE is displayed

Syntax:
[SET] IDline ON|OFF

Description:
The SET IDLINE set command determines if the idline for a file is displayed or not.

Compatibility:
XEDIT: N/A
KEDIT: Compatible.

Default:
ON
