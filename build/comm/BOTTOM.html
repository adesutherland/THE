BOTTOM - move to the bottom of the file

Syntax:
Bottom

Description:
The BOTTOM command moves to the very end of the current file. The last line of the file is set to the current line .

Compatibility:
XEDIT: Compatible.
KEDIT: Compatible.

See Also:
FORWARD, TOP
