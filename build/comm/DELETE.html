DELETE - delete lines from a file

Syntax:
DELete [target]

Description:
The DELETE command removes lines from the current file. The number of lines removed depends on the target specified. Lines are removed starting with the focus line .

Compatibility:
XEDIT: Compatible.
KEDIT: Compatible.

Default:
1

See Also:
SOS DELLINE

Status:
Complete.
