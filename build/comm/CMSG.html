CMSG - display text on command line

Syntax:
CMSG [text]

Description:
The CMSG command, primarily used in macros, displays text on the command line. The cursor is placed after the last character displayed.

Compatibility:
XEDIT: Compatible.
KEDIT: Compatible.

See Also:
EMSG, MSG

Status:
Complete.
