# NEXT
**move forward in the file a number of lines**

## Syntax
```text
Next [relative target]
```

## Description
The NEXT command moves the current line forwards the number of lines specified by the relative
target . This relative target can only be a positive integer or the character "*".

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## Default

## See Also
DOWN, UP

## Status
Complete.
