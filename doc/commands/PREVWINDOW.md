# PREVWINDOW
**switch focus of editing session to another file**

## Syntax
```text
PREVWindow
```

## Description
The PREVWINDOW command moves the focus of the editing session to the other screen (if SET
SCREEN 2 is in effect) or to the previous file in the ring .

## Compatibility
XEDIT: N/A
KEDIT: N/A

## See Also
NEXTWINDOW, EDIT, SET SCREEN
