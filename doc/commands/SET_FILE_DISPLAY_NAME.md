# SET FILE DISPLAY NAME
**change the display filename of the file being**

edited

## Syntax
```text
[SET] FDISPLAY displayname
```

## Description
The SET FDISPLAY command allows the user to change the display filename of the file currently
being edited as shown on the IDLINE .

## Compatibility
XEDIT: N/A
KEDIT: N/A
