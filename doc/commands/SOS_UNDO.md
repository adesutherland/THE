# SOS UNDO
**undo changes to the current line**

## Syntax
```text
SOS UNDO
```

## Description
The SOS UNDO command causes the contents of the focus line (or the command line ) to be reset to
the contents before the cursor was positioned there.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.
