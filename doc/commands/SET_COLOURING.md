# SET COLOURING
**enable or disable syntax highlighting**

## Syntax
```text
[SET] COLOURING ON|OFF [AUTO|parser]
```

## Description
The SET COLOURING command is a synonym for the SET COLORING command.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default
ON AUTO

## See Also
SET COLORING

## Status
Complete.
