# RESET
**cancel the marked block or prefix commands or both**

## Syntax
```text
RESet ALL|Block|Prefix|THIGHlight
```

## Description
The RESET command unmarks any marked block or outstanding prefix commands, the text highlight
area or all or the above.

## Compatibility
XEDIT: Adds Block, All and THIGHlight options.
KEDIT: Missing some features.

## Status
Complete.
