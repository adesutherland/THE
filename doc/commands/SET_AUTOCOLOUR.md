# SET AUTOCOLOUR
**specifies which parser to use for syntax**

highlighting

## Syntax
```text
[SET] AUTOCOLOUR mask parser [MAGIC]
```

## Description
The SET AUTOCOLOUR command is a synonym for the SET AUTOCOLOR command.

## Compatibility
XEDIT: N/A
KEDIT: Similar. KEDIT does not have MAGIC option.

## Default
See QUERY AUTOCOLOR

## See Also
SET AUTOCOLOR

## Status
Complete.
