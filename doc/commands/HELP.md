# HELP
**edit help file for THE**

## Syntax
```text
HELP
```

## Description
The HELP command displays help for the editor. Uses THE_HELP_FILE environment variable to
point to the help file. See Appendix 1 for details on this and other environment variables.

## Compatibility
XEDIT: Similar in concept.
KEDIT: Similar in concept.

## Status
Complete.
