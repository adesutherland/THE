# CANCEL
**quit from all files in the ring**

## Syntax
```text
CANcel [SAVE]
```

## Description
The CANCEL command exits from THE quickly by executing a QQUIT command for every file in
the ring that does not have any outstanding alterations and saving files with alterations if SAVE is
specified.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.
