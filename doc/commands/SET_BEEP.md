# SET BEEP
**turn on or off the audible alarm when displaying errors**

## Syntax
```text
[SET] BEEP ON|OFF
```

## Description
The SET BEEP command allows the user to determine if an audible alarm is sounded when an error is
displayed.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default
OFF

## Status
Complete.
