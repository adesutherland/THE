# TOP
**move to the top of the file**

## Syntax
```text
TOP
```

## Description
The TOP command moves to the very start of the current file. The Top-of-File line is set to the
current line .

TOP is equivalent to BACKWARD *.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## See Also
