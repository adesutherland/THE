# SET SPILL
**specify if a string target can span multiple lines**

(unavailable)

## Syntax
```text
[SET] SPILL ON|OFF|WORD
```

## Description
The SET SPILL set command determines how characters are spilt off the end of a line when the
length of the line exceeds the truncation column.

## Compatibility
XEDIT: Compatible.
KEDIT: N/A

## Default
OFF

## Status
Not started.
