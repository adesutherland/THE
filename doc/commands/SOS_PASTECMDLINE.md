# SOS PASTECMDLINE
**copy contents of marked block to command line**

## Syntax
```text
SOS PASTECMDline
```

## Description
The SOS PASTECMDLINE command copies the contents of the marked block to the command line
at the current cursor location.
Marked blocks that span one line only are allowed to be pasted.
