# SOS FIRSTCOL
**move cursor to first column of field**

## Syntax
```text
SOS FIRSTCOl
```

## Description
The SOS FIRSTCOL command moves the cursor to the first column of the cursor field .

## Compatibility

XEDIT: N/A
KEDIT: Compatible

## See Also
SOS FIRSTCHAR, SOS LASTCOL

Complete.
