# SET NONDISP
**specify character to display for non-displaying**

characters

## Syntax
```text
[SET] NONDisp character
```

## Description
The SET NONDISP command allows the user to change the character that is displayed for
non-displaying commands when SET ETMODE is OFF.

## Compatibility
XEDIT: Compatible.
KEDIT: N/A

## Default
#

## See Also
SET ETMODE

## Status
Complete.
