# SOS DELBACK
**delete the character to the left of the cursor**

## Syntax
```text
SOS DELBAck
```

## Description
The SOS DELBACK command moves the cursor one character to the left and deletes the character
now under the cursor.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## See Also
SOS DELCHAR, SOS CUADELCHAR
