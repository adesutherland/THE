# NEXTWINDOW
**switch focus of editing session to another file**

## Syntax
```text
NEXTWindow
```

## Description
The NEXTWINDOW command moves the focus of the editing session to the other screen (if SET
SCREEN 2 is in effect) or to the next file in the ring .

## Compatibility
XEDIT: N/A
KEDIT: N/A

## See Also
PREVWINDOW, EDIT, SET SCREEN
