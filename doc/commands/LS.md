# LS
**list the specified directory as an editable file**

## Syntax
```text
LS [file specification]
```

## Description
The LS command displays all files matching the specified file specification .
When no parameter is supplied, all files in the current directory are displayed subject to any SET
DIRINCLUDE restrictions.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## See Also
DIRECTORY, SET DIRINCLUDE

## Status
Complete.
