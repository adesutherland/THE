# SET HEXDISPLAY
**turn on or off display of character under cursor**

## Syntax
```text
[SET] HEXDISPlay ON|OFF
```

## Description
The SET HEXDISPLAY command turns on or off the display of the character under the cursor on the
status line .

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default
ON

## Status
Complete
