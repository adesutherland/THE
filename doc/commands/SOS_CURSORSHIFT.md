# SOS CURSORSHIFT
**move text to right of cursor to cursor**

## Syntax
```text
SOS CURSORSHIFT
```

## Description
The SOS CURSORSHIFT command moves text in the focus line so that the first non-blank character
to the right of the cursor is shifted to under the cursor position.
