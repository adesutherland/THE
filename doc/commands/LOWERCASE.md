# LOWERCASE
**change uppercase characters to lowercase**

## Syntax
```text
LOWercase [target]
```

## Description

The LOWERCASE command changes all uppercase characters in all lines up to the target line to
lowercase. All other characters remain untouched.

## Compatibility
XEDIT: Equivalent of LOWERCAS command.
KEDIT: Compatible.
