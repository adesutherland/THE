# REDIT
**re-edit the current file**

## Syntax
```text
REDIT
```

## Description
The REDIT command removes the current file from ring, discarding any changes since the file was
last saved explicitly with the SAVE or SSAVE command or the original file version and loads the file
back into the ring.

## Compatibility
XEDIT: N/A
KEDIT: N/A

## See Also
CANCEL, SAVE
