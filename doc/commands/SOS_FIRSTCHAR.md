# SOS FIRSTCHAR
**move cursor to first non-blank of field**

## Syntax
```text
SOS FIRSTCHar
```

## Description
The SOS FIRSTCHAR command moves the cursor to the first non-blank character of the cursor field.
For the prefix area the cursor moves to the first column.

## Compatibility
XEDIT: N/A
KEDIT: Compatible
