# NFUP
**locate backwards the line which does NOT begin with the**

supplied string

## Syntax
```text
NFUp [string]
```

## Description
The NFUP command is a synonym for the NFINDUP command.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## See Also
FIND, FINDUP, NFIND, NFINDUP

Complete
