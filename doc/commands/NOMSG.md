# NOMSG
**execute a command suppressing any messages**

## Syntax
```text
NOMSG command [arguments]
```

## Description
The NOMSG command executes the supplied command but suppresses messages that would normally
be displayed as a result of the command.
Optional arguments may be passed to the command .
