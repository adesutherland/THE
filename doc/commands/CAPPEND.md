# CAPPEND
**append text after column pointer**

## Syntax
```text
CAppend [text]
```

## Description
The CAPPEND command moves the column pointer to the end of the focus line and appends the
specified text .
If no text is specified, the column pointer moves to the first trailing space.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.
