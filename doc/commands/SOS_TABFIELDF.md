# SOS TABFIELDF
**move cursor to next enterable field**

## Syntax
```text
SOS TABFIELDf
```

## Description
The SOS TABFIELDF command causes the cursor to move to the next enterable field on the screen.
This command is intended to mimic the behaviour of the TAB key on a 3270 terminal.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.
