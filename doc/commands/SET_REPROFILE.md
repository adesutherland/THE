# SET REPROFILE
**indicate if profile file to be executed for all files**

## Syntax
```text
[SET] REPROFile ON|OFF
```

## Description
The SET REPROFILE command allows the user to determine if the profile file is to reexecuted for
files subsequently edited.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default
OFF

## See Also
XEDIT, EDIT, THE
