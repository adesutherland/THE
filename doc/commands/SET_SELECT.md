# SET SELECT
**sets the selection level for the specified lines**

## Syntax
```text
[SET] SELect [+|-]n [target]
```

## Description
The SET SELECT command sets the selection level for the indicated lines equal to n (if no signs are
specified) or adds or subtracts n from the selection level currently set for the lines in the target. n
cannot be larger than 50000

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## Default

## See Also
