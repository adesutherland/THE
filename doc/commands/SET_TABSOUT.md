# SET TABSOUT
**set tab processing on file output**

## Syntax
```text
[SET] TABSOut ON|OFF [n]
```

## Description
The SET TABSOUT command determines if spaces written to a file are to be compressed to tabs and
if so how many spaces.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default

OFF 8

## See Also
SET TABSIN
