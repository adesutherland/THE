# SET DISPLAY
**specify which level of lines to display**

## Syntax
```text
[SET] DISPlay n [m|*]
```

## Description
The SET DISPLAY command sets the selection level for lines to be displayed on the screen.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## Default

## See Also
SET SCOPE, SET SELECT, ALL

## Status
Complete.
