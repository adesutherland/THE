# SET TOFEOF
**specify if TOF and BOF lines are displayed**

## Syntax
```text
[SET] TOFEOF ON|OFF
```

## Description
The SET TOFEOF command allows the user to specify if the Top-of-File line and the Bottom-of-File
line are displayed.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.

## Default
ON

## Status
Complete.
