# SOS ADDLINE
**add blank line after focus line**

## Syntax
```text
SOS ADDline
```

## Description
The SOS ADDLINE command inserts a blank line in the file following the focus line. The cursor is
placed in the column under the first non-blank in the focus line.

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## See Also
SOS LINEADD, SOS DELLINE
