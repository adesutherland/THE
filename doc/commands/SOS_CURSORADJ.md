# SOS CURSORADJ
**move first non-blank character to cursor**

## Syntax
```text
SOS CURSORAdj
```

## Description
The SOS CURSORADJ command moves text in the focus line so that the first non-blank character
appears under the cursor position.

## Compatibility
XEDIT: N/A
KEDIT: Compatible.
