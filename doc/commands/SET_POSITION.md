# SET POSITION
**determine if LINE/COL is displayed on idline**

## Syntax
```text
[SET] POSition ON|OFF
```

## Description
The SET POSITION command allows the user to turn on or off the display of LINE/COL on the
idline .

## Compatibility
XEDIT: N/A
KEDIT: N/A

## Default
ON

## Status
Complete.
