# SOS LINEADD
**add blank line after focus line**

## Syntax
```text
SOS LINEAdd
```

## Description
The SOS LINEADD command inserts a blank line in the file following the focus line . The cursor is
placed in the column under the first non-blank in the focus line .

## Compatibility
XEDIT: Compatible.
KEDIT: Compatible.

## See Also
SOS ADDLINE, SOS LINEDEL
