# DOSNOWAIT
**execute an operating system command - no prompt**

## Syntax
```text
DOSNowait command
```

## Description
The DOSNOWAIT command executes the supplied operating system command not waiting for the
user to be prompted once the command has completed.

XEDIT: N/A
