# OSREDIR
**execute an operating system command and capture output**

## Syntax
```text
OSRedir filename command [arguments ...]
```

## Description
The OSREDIR command executes the supplied operating system command and redirects output
destined for STDOUT and STDERR to the specified filename .
Optional arguments may be supplied to the command .
