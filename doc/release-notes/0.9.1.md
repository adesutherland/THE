CRXTHE 0.9.1 is an independently maintained fork based on Mark Hessling's THE 4.0. Installers and portable archives include a private cREXX runtime; Regina remains optional and is installed separately.

### Changes since 0.9.0

- F7 forms honour declared colours in the console and browser. The demo hides caller text and prefix numbers, cycles between its two editable fields, and restores the cursor and footer after Enter or Escape.
- Browser form actions stay visible when the form body scrolls.
- Retained tabs consistently display as arrows and use the correct cursor position and U+0009 status preview. Default Tab input inserts spaces; stored tab bytes are preserved.
- Status repainting removes stale colours and Unicode preview text. Windows console output stays within logical cells.
- Editor, help, browser title, profiles and installer consistently identify CRXTHE 0.9.1. Updated Windows first-use instructions are included.
- Tag pushes now build, package, test, sign/notarize macOS and publish automatically, following the cREXX-RAG release pattern. Windows SimplySign remains the separate local signing/replacement pass.

### Installation

Use the Windows x64 `-setup.exe` or macOS ARM64 `.pkg`. macOS requires version 15 or later. Keep bundled cREXX selected for the default setup, or choose a compatible installed cREXX with automatic bundled fallback. Portable ZIPs must be fully extracted; use `bin/crxthe` or `bin/crxthe.cmd`.

See [Windows installation and first use](https://github.com/adesutherland/THE/blob/v0.9.1/doc/Windows-Readme.txt), [first launch](https://github.com/adesutherland/THE/blob/v0.9.1/doc/first-launch.md) and [runtime/cache options](https://github.com/adesutherland/THE/blob/v0.9.1/doc/rexx-interpreters.md).

### Qualification and limits

Adrian's manual Windows smoke test passed the product changes. Automated regressions cover both macro engines, tab/Unicode repainting, F7 forms, five syntax categories and installed runtime/cache selection. The tag workflow runs these checks once on each applicable platform and verifies clean source manifests and payload hashes. Optional parser skips remain visible in the run.

The browser UI remains experimental. The legacy Windows console may display a base-character fallback for arbitrary combining sequences; stored text is unchanged. A separate LLM-driver Delete/save persistence defect remains open ([details](https://github.com/adesutherland/THE/blob/v0.9.1/doc/ui-render-followup.md#separate-observation)). This release qualifies this fork; upstream THE and live XEDIT compatibility are not claimed. Third-party macro originals, patches and ports are excluded.
